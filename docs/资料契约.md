# 资料契约

所有记录均为本地合成演练资料，不含真实个人、企业或医疗信息。文件使用 UTF-8 JSON，金额和数量以各字段说明为准。空串、零、缺报、争议分别保留其含义，不可互相替换。

记录的 `id` 只在本资料类别内唯一。`known`、`known_day`、`known_week`、`known_month` 表示收到事实的时间；实际发生时间另有字段。日序和分钟是演练的相对时间，未另行说明的区间均左闭右开。月份为演练年度的自然月。

`data/schema.json` 声明字段、类型和显式引用。数组与对象内的业务关系按相应中文字段说明解释；资料检查器不替代这些业务关系的判断。原始与后补记录共存，文件排列不代表业务生效顺序。

## products

可换算单位与规格定义。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 商品规格 |
| `name` | string | 品名 |
| `grade` | string | 等级 |
| `unit` | string | 单位 |
| `kg_per_unit` | number | 每单位千克 |

## markets

报价市场与地区。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 市场 |
| `region` | string | 地区 |
| `report_days` | array | 正常周几报送 |

## quotes

价格为每报告单位分；交易量为报告单位数。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 报价 |
| `market` | string | 市场 |
| `product` | string | 商品 |
| `day` | integer | 日序 |
| `price_cents` | integer | 单价 |
| `volume` | number | 交易量 |
| `state` | string | 报送状态 |
| `known_day` | number | 知悉日序 |

显式引用：`market` → `markets.id`；`product` → `products.id`。

## substitutions

规格接续须有明确审批和重叠日。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 关系 |
| `old` | string | 旧规格 |
| `new` | string | 新规格 |
| `overlap_days` | array | 指定重叠日 |
| `state` | string | 审批状态 |
| `known_day` | number | 知悉日 |

显式引用：`old` → `products.id`；`new` → `products.id`。

## baskets

篮子定义；权重不从新闻获取。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 篮子 |
| `base_day` | integer | 基期日 |
| `weights` | object | 商品权重 |
| `regions` | object | 地区权重 |
| `max_missing_weight` | number | 最大缺失权重 |
| `predecessor` | string | 前序篮子或空 |

## subscriptions

机构采用篮子、日历与暂估规则。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 订阅 |
| `basket` | string | 篮子 |
| `weekdays` | array | 接收周几 |
| `maturity` | string | 暂估及定稿或只定稿 |
| `recipient` | string | 接收机构 |

显式引用：`basket` → `baskets.id`。

## revisions

对旧报价的补报和复核，不预置指数。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 复核 |
| `quote` | string | 报价 |
| `decision` | string | 采用或退回 |
| `price_cents` | integer | 更正价 |
| `volume` | number | 更正量 |
| `known_day` | number | 知悉日序 |

显式引用：`quote` → `quotes.id`。

## received_deliveries

合作端已有收件记录；本地可能未确认。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 业务交付编号 |
| `subscription` | string | 订阅 |
| `version` | string | 版本 |
| `received_day` | number | 接收日 |
| `acknowledged` | boolean | 本地已确认 |

显式引用：`subscription` → `subscriptions.id`。

## calendar

机构日历对应演练日期；日序从十月一日开始。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 日期编号 |
| `day` | integer | 日序 |
| `date` | string | 自然日期 |
| `weekday` | integer | 周一为一 |
