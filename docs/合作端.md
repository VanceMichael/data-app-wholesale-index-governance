# 合作端接口

这是独立接收方的本地合成服务，只处理交付接受事实，不判断分析内容或服务能力。运行 `npm run receiver`，默认地址为 `http://127.0.0.1:4317`。`RECEIVER_PORT` 可换端口，`RECEIVER_STATE` 可指定独立状态目录。

`POST /acceptances` 接收 JSON 对象 `id` 和 `payload`。同一业务编号与相同内容重送仍是原接受，返回 200；首次返回 201。同编号不同内容返回 409。编号由发送方定义，但已存在的业务编号保持兼容。

`GET /receipts/{经过URL编码的业务编号}` 查合作端事实，存在返回含原内容和接受时间的 200 对象，不存在返回 404。网络失败表示事实未知，不能解释成拒绝。

`POST /controls/drop-next-ack` 是合作端演练控制：下一份合法接受记录会正常保存，然后连接中断。此入口不修改业务判断。状态保存于本地 JSON，服务重启保留。清理演练时使用独立的新状态目录，不改业务资料。

`data/receiver_seed.json` 保存合作方已有的接受记录。`npm test` 对真实 HTTP 接收、确认丢失、查询与冲突做隔离检查；它不验证业务应用的后续处理。
